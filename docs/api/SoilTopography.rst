SoilTopography
==============

Helpers for backslope / front-face topography scripting payloads.
Terrain type strings match the RSWall UI (``Infinite``, ``Broken``,
``User-defined``). Length keys may use alias names (for example ``x``) or
historical ``*Meters`` wire keys; values are still **project-native** length.
